SpeechFlow AI

SpeechFlow AI is a platform for collecting and validating speech dataset for Indian languages.

Goals

	Build high-quality regional language dataset
	Automate dataset validation
	Learn DevOps and Platform Engineering
	Deploy using Docket and Kubernetes

Planned Technology Stack

Frontend:
	React
	Vite

Backend:
	Node,js
	Express

Database:
	PostgreSQL
	Supabase

Infrastructure:
	Docker
	Kubernetes
	GitHub Actions

Monitoring:
	Grafana
	Prometheus
