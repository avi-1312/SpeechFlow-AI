SpeechFlow AI Architecture V1

Overview

Speechflow AI is a speech dataset colllection and Validation platform.

The Platform allows contributors to upload speech recordings and transcripts which are reviewed before becoming part of the dataset.

Components

Frontend
	React
	Vite

Responsibilities

	User login
	Upload recordings
	Manage transcripts
	Review submission
	Dashboard

Backend API

	Node.js
	Express

Responsibilities
	
	Authentication
	Recording management
	Review workflow
	Dashboard APIs

Database
	
	PostgreSQL

Responsibilities

	Users
	Recordings
	Reviews
File Storage	

	Supabase Storage

	Serve playback files
