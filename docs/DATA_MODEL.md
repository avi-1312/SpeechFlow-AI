SpeechFlow AI Data Model

Recordings

A Speech sample submitted by a contributor.

Fields:
	ID
	Audio File
	Transcript
	Language
	Duration
	Status
	Created Date

Speaker

Information about the contributor.

Fields:

	ID
	Name
	Gender
	Age Group
	Region

Review

Validation performed by reviewers.

Fields:
	
	ID
	Reviewer
	Decision
	Comments
	Date

User

Platform users.

Roles:
	
	Admin
	Reviewer
	Contributor

Supported Languages

	Marathi
	English
	Hindi
	Gujarati
